# GV Tools

Next.js + Tailwind로 만든 사내 업무용 웹 도구 모음입니다. 서버 전송 없이 100% 브라우저 클라이언트 사이드에서 안전하고 빠르게 동작합니다.

## 제공 기능

### 1. Excel ➜ CSV 변환기 (`/excel-to-csv`)
- **샘플 템플릿 매핑 변환 (추천)**:
  - 기준 샘플 CSV(예: `송장번호 샘플.csv`)를 업로드하거나 '기본 송장 템플릿'을 적용
  - 샘플의 **인코딩(EUC-KR/CP949)**, **줄바꿈(CRLF)**, **구분자**, **헤더 컬럼** 세팅을 100% 감지 및 복제
  - 원본 엑셀 컬럼과 템플릿 컬럼 간 **스마트 자동 매핑(Auto Match)** + 고정값(예: 배송업체 "CJ대한통운") 직접 입력 지원
  - 송장번호나 주문번호 같은 긴 숫자의 **지수 표기(`5.97E+11`) 왜곡 방지 및 온전한 텍스트 보존**
  - 실시간 매핑 미리보기 및 원클릭 CSV 다운로드
- **일반 시트 직접 변환**:
  - 단일 시트 변환, 전 시트 개별 일괄 다운로드, 전 시트 ZIP 압축 다운로드
  - UTF-8 BOM, EUC-KR, 표준 UTF-8 인코딩 선택 및 구분자 설정

### 2. WebP 변환기 (`/webp`)
- PNG, JPG(JPEG) 파일 전역 드래그&드롭 또는 선택 업로드 지원
- 브라우저 캔버스를 이용한 클라이언트 사이드 변환 → 서버 비용/지연 없음
- 출력 품질(40~100%) 슬라이더 제공 + 자동 4MB 이하 용량 제한
- 변환 전/후 용량 비교와 평균 압축률 표시
- 개별 다운로드와 목록 비우기 기능

### 3. 시리얼 매칭 도구 (`/serial`)
- `Serial_base.xlsx`와 주문/출고 데이터를 기반으로 품번 및 배송지, 매장코드를 자동 대조하여 시리얼 번호를 일괄 입력 및 다운로드


## 실행 방법

```bash
npm install
npm run dev
```

그 다음 [http://localhost:3000](http://localhost:3000)으로 접속하면 뷰를 확인할 수 있습니다.

## 사용 방법

1. PNG 또는 JPG 파일을 드래그&드롭하거나 "파일 선택" 버튼을 눌러 업로드합니다.
2. 필요한 경우 상단의 슬라이더로 기본 출력 품질을 조절합니다. 결과물이 4MB보다 크면 자동으로 더 낮은 품질을 적용해 제한을 맞춰 줍니다.
3. 업로드가 끝나면 하단 "변환 결과" 영역에서 각 WebP 파일을 다운로드하거나 목록에서 제거할 수 있습니다. 품질이 4MB 제한으로 인해 낮아진 경우 카드에 표기됩니다.
4. 여러 파일을 한 번에 업로드해도 브라우저에서 순차로 처리합니다. 변환한 파일은 "변환 목록 비우기" 버튼으로 초기화할 수 있습니다.

> ⚠️ 변환 과정은 전부 브라우저 메모리에서 일어나기 때문에, 큰 이미지를 대량으로 올리면 기기 성능에 따라 변환 시간이 길어질 수 있습니다.
